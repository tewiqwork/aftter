# aftter

> **after dark • clean community • powerful moderation**

A lightweight Discord bot made for Minecraft communities.

## ✦ Features

- 🛡️ Moderation
  - `/warn`
  - `/warnings`
  - `/kick`
  - `/ban`
  - `/timeout`
  - `/clear`

- 🔗 Anti-Link
  - Automatically blocks unwanted links
  - Discord invites are blocked
  - Moderation permissions bypass the filter

- 🔊 Temporary Voice
  - Join `🔎・create [+]`
  - aftter automatically creates a personal voice channel
  - The channel is automatically deleted when everyone leaves

- ⚔️ Clans
  - Create your own clan
  - Clan tags in nicknames: `[TAG] Username`
  - Automatic clan roles
  - Add members
  - Leave or delete clans

- 🎮 Fun
  - `/8ball`
  - `/coin`
  - `/dice`
  - `/ship`

- 🧹 Server Setup
  - `/nuke`
  - `/nuke-confirm`
  - Rebuilds the server using aftter's clean layout
